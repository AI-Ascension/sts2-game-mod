# Forced native terminal probe

This source-owned fixture is excluded from normal addon builds. Build with
`-p:EnableTerminalProbe=true`, then launch only the explicitly isolated practice fixture with
`STS2_TERMINAL_PROBE=1` and seed `AIASCENSIONTERMINALTEST1`.

The probe starts a native run, selects the final act through host APIs, installs a synthetic
prior win time and records an active observation. It enters the final boss map coordinate,
force-kills its enemies, ends that test combat through the host, and activates the uniquely
visible, enabled native Proceed control after bounded readiness checks. The resulting native
victory event is a terminal witness even while the manager reports the run in progress.
It checks victory projection, final player state, no legal mutation, rejection of late attachment,
unchanged stale win time and absent win time, then restoration of the fresh terminal observation.

This forcibly ends a test run. A PASS is native terminal-observation evidence only; it is never
LLM control, completed combat, campaign victory, replay, or training data. Normal gameplay must
use a build without this flag. This probe must not interrupt a normally played campaign.
